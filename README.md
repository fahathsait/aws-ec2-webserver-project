📌 AWS EC2 Web Server Deployment Project

This project demonstrates deploying a custom static website on an Amazon EC2 Linux server using Apache Web Server.

🚀 Tasks Completed
Launched EC2 instance (Amazon Linux 2023)

Connected using EC2 Instance Connect

Installed & configured Apache
Deployed a custom HTML website
Restarted and enabled Apache service
Tested public website using EC2 Public IP
